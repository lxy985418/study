# 2026-11-14 法律知识点总结

按当天实际讲解与复习内容整理。先读规则，再对照易错点；已讲、已订正与已经掌握分别判断。

## 民事权利能力与行为能力

权利能力回答“能否享有权利、承担义务”，行为能力回答“能否自己独立实施行为”。宝宝能拥有财产，不代表能自己订合同。

| 人的情况 | 行为能力判断 |
|---|---|
| 正常辨认的成年人 | 完全民事行为能力人 |
| 16周岁以上不满18周岁，以劳动收入为主要生活来源 | 视为完全民事行为能力人 |
| 8周岁以上未成年人，不符合上述例外 | 通常为限制民事行为能力人 |
| 不满8周岁 | 无民事行为能力人 |
| 成年人不能完全辨认自己的行为 | 限制民事行为能力人 |
| 成年人不能辨认自己的行为 | 无民事行为能力人 |

16岁和劳动收入为主要生活来源须同时满足。偶尔兼职不够；15岁即使靠工资生活，也不适用该例外。疾病名称不能替代辨认能力判断。

限制行为能力人可以独立实施两类行为：纯获利益；与年龄、智力、精神健康状况相适应。接受不附义务的赠与通常是纯获利益，自己把钱送出去不是；购买普通文具虽要付钱，仍可能与能力相适应。

相适应没有统一金额线，要看生活关联、理解及预见后果的能力、标的数量和价款等。付得起不等于相适应，金额也并非无关。

无行为能力人独立实施的民事法律行为无效，不能用事后追认补正；应由法定代理人依法代理。限制行为能力人超出可独立实施范围、未经同意或追认的其他行为，才按效力待定规则判断。

自然人权利能力从出生到死亡；涉及继承、受赠等胎儿利益保护时视为具有权利能力，娩出为死体则自始不存在。

## 民事法律行为的四类效力

| 类型 | 如何理解 |
|---|---|
| 有效 | 符合生效要求，发生相应效力 |
| 无效 | 自始没有法律约束力 |
| 可撤销 | 撤销前有效，依法撤销后自始没有法律约束力 |
| 效力待定 | 尚需追认等确定效力，不能先说已经无效 |

重大误解、欺诈、胁迫、显失公平属于已学可撤销事由。受欺诈方可以保留交易，不能把商家欺诈直接判成合同当然无效。显失公平要同时看利用危困、缺乏判断能力等处境，以及成立时利益明显失衡；单纯后悔或按正常市价成交不够。

第三人欺诈：交易对方知道或者应当知道，受害方才可据此请求撤销。第三人胁迫不以交易对方知情为必要条件。

| 撤销事由 | 对应期间及起点 |
|---|---|
| 重大误解 | 知道或应当知道撤销事由起90日 |
| 欺诈、显失公平 | 知道或应当知道撤销事由起1年 |
| 胁迫 | 胁迫行为终止起1年 |

还要检查行为发生后5年的最长限制，以及知情后是否有效放弃撤销权。不是一律能等5年。上述撤销须请求法院或仲裁机构处理。

无效重点：无行为能力人独立行为、双方虚假意思表示、恶意串通损害他人合法权益、违背公序良俗等。违法不等于一律无效，要审具体规定；租赁未备案不因此无效，租期超过20年通常只是超出部分无效。假买卖隐藏真赠与，表面行为与隐藏行为分别审查。

限制行为能力人追认催告：法定代理人收到通知起30日内追认，期满不表态视为拒绝。追认前善意相对人可以通知撤销；不要与欺诈等须向法院、仲裁机构请求撤销混用。

撤销后的财产原则返还，不能返还或无必要返还则折价补偿；过错损失赔偿另审。没有欺诈故意，不等于没有任何返还或过错责任。受胁迫签放弃声明，也须审查声明本身，不能只凭签名下结论。

## 监护与代理

未成年人的监护人首先是父母；父母死亡或无监护能力后：祖父母、外祖父母同顺位，其次兄、姐，再其次经法定机构同意的其他愿意担任者。成年人需要监护时：配偶；父母、子女；其他近亲属；经法定机构同意的其他愿意担任者。

监护应最有利于被监护人，非为维护其利益不得处分其财产，并尊重与其年龄智力相适应的真实意愿。孩子反对要认真听取，但不等于拥有所有事项的绝对否决权。

遗嘱指定监护是担任监护人的父母为子女安排；意定监护是有完全行为能力的成年人书面安排自己未来的监护。争议可直接申请法院指定，不必先找居委会。监护资格撤销不免除法定抚养等费用义务；恢复资格须符合法定条件，对被监护人实施故意犯罪的父母或子女不适用该项恢复规定。

| 代理情况 | 关键判断 |
|---|---|
| 有权代理 | 在权限内以本人名义实施，对被代理人发生效力 |
| 普通无权代理 | 未追认，对被代理人不发生效力；先排除表见代理 |
| 表见代理 | 有可信权利外观，相对人有理由相信有权且善意无过失，无须追认 |
| 自己代理、双方代理 | 原则禁止，分别审被代理人或双方同意、追认例外 |
| 转委托 | 原则须同意或追认；紧急维护本人利益确有必要有例外 |

## 法人及组织责任

法人是组织，法定代表人是代表组织活动的负责人。法人分营利、非营利、特别法人；非营利可收费、有结余，但不得向出资人等分配利润。居委会、村委会属于特别法人中的基层群众性自治组织法人。

子公司有法人资格，依法独立承担责任；分公司无法人资格，责任由设立它的公司承担。个人独资企业无法人资格、投资人承担无限责任；一个股东的有限公司仍是公司法人。不能只凭“一个人投资”混为一谈，也不能把有限责任理解为不存在任何法定例外。

吊销营业执照不等于公司法人立刻终止；清算期间仍存续，依法应清算注销的，完成相关程序才终止。

## 宣告失踪与死亡

失踪满2年可以申请宣告失踪，主要解决财产代管，不直接启动继承。一般下落不明满4年、意外事件满2年可申请宣告死亡；意外且有关机关证明不可能生存，不受上述2年限制。须法院依法宣告，不是时间到自动发生。

一般宣告死亡，以判决作出日视为死亡日；因意外事件下落不明被宣告死亡，以意外发生日视为死亡日。本人回来须依法撤销宣告；继承取得财产者应返还，无法返还适当补偿，隐瞒真相致宣告死亡并取得财产者还须赔偿相应损失。

死亡宣告撤销后婚姻原则自行恢复；配偶再婚或依法书面声明不愿恢复，则不恢复。子女已被依法收养，不能仅以未经本人同意主张无效。实际生存期间行为，不因死亡宣告而当然无效。

## 当天易错点与复习要求

重点纠正能力术语、赠出与受赠、无效与待追认、第三人欺诈知情条件、监护顺位、表见代理、子分公司，以及宣告死亡日期。收尾七题结论正确，不等于所有理由规范或整章掌握。

**自查：**先判断年龄和辨认能力，再判行为类型；判断合同有效，不代表财产已经转移；先辨组织形式，再判断由谁承担债务。
