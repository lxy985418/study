# M01｜民事权利能力与民事行为能力

日期：2026年11月14日。范围：今天实际讲解、练习和订正的内容。

## 1. 先分清两种能力

| 概念 | 解决的问题 | 今天的例子 |
|---|---|---|
| 民事权利能力 | 能否依法享有民事权利、承担民事义务 | 刚出生的宝宝可以拥有受赠财产 |
| 民事行为能力 | 能否通过自己的行为独立实施民事法律行为 | 宝宝不能自己订合同，可由法定代理人依法代理 |

**有权利能力，不等于能独立完成交易。**判断能否独立接受赠与，不能只答“他有民事权利能力”，还要用行为能力及具体行为规则解释。

自然人的民事权利能力从出生时起到死亡时止。

### 胎儿的特殊保护

- 涉及遗产继承、接受赠与等胎儿利益保护的，视为具有民事权利能力。
- 胎儿娩出时为死体的，其民事权利能力自始不存在。
- 不要写成“胎儿在任何事项上都无条件具有民事权利能力”。

## 2. 行为能力分类

以下按题目给定的年龄、辨认能力及劳动收入条件判断，不自行补充事实。

| 人的情况 | 分类 |
|---|---|
| 18周岁以上，具备正常辨认能力 | 通常是完全民事行为能力人 |
| 16周岁以上、不满18周岁，以自己的劳动收入为主要生活来源 | 视为完全民事行为能力人 |
| 8周岁以上、不满18周岁的未成年人，能够正常辨认，且不符合上述劳动收入例外 | 限制民事行为能力人 |
| 不满8周岁的未成年人 | 无民事行为能力人 |
| 不能完全辨认自己行为的成年人 | 限制民事行为能力人 |
| 不能辨认自己行为的成年人 | 无民事行为能力人 |
| 8周岁以上、不能辨认自己行为的未成年人 | 适用无民事行为能力人的相关规定 |

**成年人不一定都有完全民事行为能力；患某种疾病，也不当然等于无民事行为能力。关键是辨认能力。**

### 劳动收入例外：两个条件一起看

1. 已满16周岁。
2. 以自己的劳动收入为主要生活来源。

| 情形 | 判断 |
|---|---|
| 17岁，主要靠自己的工资生活 | 可以视为完全民事行为能力人 |
| 17岁，偶尔兼职，但主要生活费仍由父母提供 | 不能只因有工资就适用例外 |
| 15岁，全部生活费都来自劳动收入 | 年龄条件仍不满足 |

规范术语是“完全／限制／无民事行为能力人”，不要写成“完全能力责任人”。

## 3. 限制民事行为能力人，哪些行为可以独立实施

有两条独立路径，符合其中一条即可：

1. **纯获利益的民事法律行为。**
2. **与其年龄、智力、精神健康状况相适应的民事法律行为。**

针对未成年人重点结合年龄、智力；针对限制行为能力的成年人重点结合智力、精神健康状况。

### 路径一：纯获利益

判断这个行为是否仅给本人带来法律上的利益，没有相应法律负担。

| 行为 | 对本人是否属于纯获利益 |
|---|---|
| 接受不附义务的赠与 | 通常属于 |
| 把自己的钱无偿送给别人 | 不属于，本人有财产支出 |
| 付款买普通笔记本 | 不属于纯获利益，但可能符合相适应规则 |

**“赠与”不能一概等同于“纯获利益”：先分清本人是受赠方还是赠出方。**

### 路径二：与本人能力相适应

综合考虑：

- 行为与本人生活的关联程度。
- 能否理解自己的行为，并预见相应后果。
- 交易标的、数量、价款或者报酬。
- 本人的年龄、智力、精神健康状况等。

没有适用于所有未成年人的统一金额线。

- “付得起”不能直接证明相适应。
- “金额完全无关”也不正确，价款和数量是综合因素。
- 钱是不是本人挣的，不直接决定每笔交易是否相适应。
- 题目只给出价格时，不要擅自补成“他一定无法理解后果”。

**例子：**15岁的小李花10元买普通笔记本，有付款义务，不是纯获利益；但属于与其年龄、智力相适应的行为，可以独立实施，不需要父母追认。

## 4. 能力分类与行为效力，要分两步

| 主体与行为 | 今天的判断规则 |
|---|---|
| 完全民事行为能力人进行交易 | 仍需看行为自身是否存在其他效力问题，不因能力而受限制 |
| 限制行为能力人实施上述两类可独立行为 | 可以独立有效实施 |
| 限制行为能力人实施超出适应范围的其他行为，尚未经同意或追认 | 效力待定；需要审查法定代理人的同意、追认 |
| 无行为能力人独立实施民事法律行为 | 按《民法典》第144条无效，不能套用限制行为能力人的追认规则 |

法定代理人依法代为实施行为，与“本人先独自实施、家长事后同意”是不同情况。

## 5. 今天最容易混淆的地方

| 原先容易出现的说法 | 应当怎样判断 |
|---|---|
| 未成年，所以一定没有完全行为能力 | 先审16周岁以上劳动收入例外 |
| 挣过钱，所以就是完全行为能力人 | 还要审是否为主要生活来源 |
| 钱是父母给的，所以买东西都要追认 | 审具体行为是否可独立实施 |
| 有财产支出，所以一定不能独立实施 | 虽非纯获利益，仍可能属于相适应行为 |
| 不能完全辨认＝不能辨认 | 前者通常对应限制，后者对应无行为能力 |
| 宝宝有权利能力，所以可自己订合同 | 权利归属和独立实施资格分开判断 |

## 6. 自查题

先遮住下方答案，用“分类／效力＋理由”回答。

1. 17岁，主要靠自己的劳动收入生活，独立购买电脑，是否仅因未成年就必须经父母追认？
2. 15岁，能正常辨认，接受不附义务的1000元赠与，能否独立接受？
3. 40岁，不能完全辨认自己的行为，属于哪一类？
4. 7岁独自签订买卖合同，能否通过父母事后追认而使该合同有效？
5. 胎儿涉及继承利益保护，后来娩出时为死体，其视为具有的权利能力如何处理？

### 参考答案

1. 不需要仅因未成年而追认；符合例外，视为完全民事行为能力人。行为其他效力问题另审。
2. 可以，属于限制行为能力人可独立实施的纯获利益行为。
3. 限制民事行为能力人。注意“不能完全”与“不能”。
4. 不能套用追认补正规则；无行为能力人独立实施的该行为无效。
5. 其民事权利能力自始不存在。
