## 换地方怎样继续

1. 先取得私人仓库的最新版本，打开当前进度；把本项目交给学习助手，并让它遵守AGENTS.md。
2. 从尚未作答的题继续，保留一题一答与先框架后练习；无需从M01重来。
3. 学完后让助手同时更新完整JSON、当前进度及当日学科复盘，按实际作答日期记账，再同步到私人仓库。
4. 另一设备先取得更新再开始，避免两个地方各写一份互相覆盖。
