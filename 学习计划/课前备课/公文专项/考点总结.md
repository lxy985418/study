# 公文考点总结

适用：四川事业单位公共基础中的公文部分；结合泸州报考方向准备。2026年11月23日已备，未授课、未答题。依据及条款见[资料索引](依据与考题索引.md)。优先级是教学顺序，不是统计频率或分值预测。

## 一、先判断“谁向谁、为啥发”

公文是机关履职办事的规范文书，处理涵盖拟制、办理、管理。按隶属关系与职权判上行、下行、平行，不能只比行政级别；同级不等于互相隶属，不相隶属也不要求级别相同。按是否涉密、办理紧迫性、行文关系等分类，分类维度不要混用。

| 法定文种 | 识别任务 | 重点区分 |
|---|---|---|
| 决议 | 会议讨论通过重大决策 | 决定不以“会议讨论通过”为唯一识别点 |
| 决定 | 重要决策部署、奖惩、变更撤销有关事项 | 不能把所有安排都写决定 |
| 命令（令） | 公布法规规章、重大强制措施、授衔嘉奖等 | 有法定使用主体和权限，不是语气强就用令 |
| 公报 | 公布重要决定或重大事项 | 不等于普通工作消息 |
| 公告 | 面向国内外的重要或法定事项 | 和一定范围内的通告区分 |
| 通告 | 一定范围内应遵守或周知事项 | 不是所有公开文书都用公告 |
| 意见 | 重要问题的见解与处理办法 | 具体行文方向依主体和用途判断 |
| 通知 | 传达执行、周知事项，批转转发 | 与通报的表彰、批评、告知重要情况区分 |
| 通报 | 表彰、批评，重要精神或情况 | 不是单凭“告知”二字选文种 |
| 报告 | 向上汇报、反映、答复询问 | 不夹带请示 |
| 请示 | 向上求指示或批准 | 一文一事；不能以报告代替 |
| 批复 | 答复下级请示 | 不是答复所有来文的通用文种 |
| 议案 | 政府依法提请同级人大或常委会审议 | 不等于会议讨论文件 |
| 函 | 不相隶属机关商洽、询答、请求批准及答复审批 | 不因出现“批准”就必用请示 |
| 纪要 | 会议主要情况及议定事项 | 与逐项记载发言、过程的会议记录区分 |

倡议书、简报、总结、方案等不属于这15种法定文种，但属于考纲撰写范围，不能漏学。

## 二、行文规则

上行原则上主送一个上级机关；必要抄送相关上级、同级，不抄送下级。一般不越级，特殊越级同时抄送被越过机关。除负责人直接交办等规定情形，不把机关请示直接主送领导个人。请示单事，报告不夹请示；双重领导必要时抄送另一上级。不能把“原则”“必要时”改为一律。

联合行文须看同级、必要性和职权；党委、政府各自职权范围内工作不得联合行文。联合发文用主办机关发文字号，成文日期看最后签发。部门内设机构除办公厅（室）外不得对外正式行文。下行涉及多部门权限，未协商一致不能擅自发文。

## 三、格式与改错

先识别版头、主体、版记，页码在版心外，再找发文机关、文号、签发人、标题、主送、附件说明、署名日期、抄送等。记清：上行须标签发人；成文日期不是打印日；附件说明不是附件本身；普发性特定标志公文和电报有印章例外。不要把所有格式要素当成每份文件必备项。

格式数字卡：常规A4为210×297mm；上边37±1mm、左边28±1mm；版心156×225mm。通常正文3号仿宋、标题2号小标宋；层次可用“一、（一）1.（1）”。文号示意“泸数〔2026〕8号”；日期示意“2026年3月6日”。这些是标准中的规则和事实归纳，特定格式另查，不外推为无例外。

通用文号规范：机关代字、完整年份、顺序号；年份用六角括号，号序不加“第”且不补零。通用成文日期年月日写全，月日不补零。附注讲说明事项，附件说明列名称，附件提供具体内容。信函格式首页不显示页码；命令格式用令号；纪要格式可按实际制定。格式细目以标准条款核对，不靠Markdown页面模拟实物版式。

## 四、拟制、办理、管理

拟制：起草→审核→签发。重要公文和上行文由机关主要负责人签发；联合发文须会签。发文办理：复核→登记→印制→核发。实质修改须报原签批人复审。收文办理：签收→登记→初审→承办→传阅→催办→答复，不能将起草、签发混入收文程序。

联合办理原件由主办机关归档。撤销是自始无效，废止是自废止日起失效。涉密公文传播、复制、解密和销毁须按规定，不用普通邮箱或私人群聊随意流转。本节只讲S2明确的公文处理规则，不代替完整保密法课程。

## 五、机关常用公文写作

读题先固定身份、对象、目的、材料边界和字数要求。常用骨架：通知写缘由、安排、要求；请示写必要性、具体请求及请批结语；报告写工作、问题、下一步，不能末尾顺带求批准；批复须回应请示事项；函突出平等商洽；通报写事实、评价和要求；通告说清适用范围、事项和执行要求；纪要提炼共识、分工、时限，不抄成发言流水账。

## 六、信息与事务文书

计划/方案侧重未来目标、任务、步骤、责任和保障；总结侧重已做工作、成效、问题和经验；调查报告围绕事实、分析、对策；简报突出事实和信息价值；专题材料和工作研究按问题组织证据与建议。倡议书写对象、缘由、可执行倡议；邀请信说清事由、时间地点、邀请事项及回复；感谢、慰问、祝贺分别围绕感谢事实、关怀困难、祝贺成就，避免混用。启事用于公开说明有关事项，公示公开拟定事项接受监督，声明表达立场或说明事实，均须按题目具体目的写。

共同检查：任务是否完成、要点是否有据、主体是否有权、对象是否正确、措施是否可执行、数字日期是否准确。自编示范答案不是唯一标准，更不是官方扣分表。
